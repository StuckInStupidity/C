C :
const int N = x; // en C99, OK pour VLA mais pas pour initialisation statique
int arr[N][N] = {0};int arr[N] = {0} ; -> works ONLY if N is consider const (NEEDS #define N x), otherwise memset works fine for the empty initializer '\0'
La syntaxe {0} est un raccourci : elle initialise le premier élément à 0, et tous les autres sont automatiquement mis à 0 grâce à la règle d'initialisation statique en C.

String -> char arr[N]
Array of strings -> char *arr[N] || char arr[N][N];
Char arr[N] = {0} -> {‘\0’,’\0’,..} -> empty string also : const char[N]= ""; or better : const char *s = ""; pour avoir une taille quelconque : diff principale entre (pointeur)* et (buffer)[] est une histoire de taille : s modifiable -> s = "hhjdkckd" (*s pointe vers le premier char par ex, s peut pointer n'importe quoi dans la memoire)
Char arr[N] = “string”; -> {‘s’,…’\0’,..} if N>len(string)
Char arr3[3] = {‘a’,’b’,’c’};
Char arr[N] = arr3; -> {‘a’,’b’,’c’,0,0,0…} -> N doit avoir la place pour les 3 et pour le 0 
so for safety => char arr[N]; strncpy(arr, input, N-1); arr[N-1] = '\0'; printf("%s\n");

Const char *arr[][] -> tableau de pointeurs modifiable (arr[][]) mais pas les char (arr[][][])
Const char * const arr[][] -> none of them
Const int *p -> pointeur vers un int non modifiable
Int * const p -> pointeur non modifiable mais int oui
Const int * const p -> none of them

int arr[]; int res; int arrr[][]; f(&res, arr, arrr)
void f(int *a, int *ar, int **p) -> ces deux pointeur pointent vers des int mais l'un dans un tableau l'autre un seul int
arr+i c'est le pointeur vers arr[i]
c'est pour ca que *arr -> pointe premier int du tableau et *(arr+i) pour valeur in arr[i]
et pour valeur in arrr[i][j] -> *(*(arrr+i)+j)
et pour pointeur arrr[i][j] -> *(arrr+i)+j

char **argv	pointer to pointer	      scattered strings	     very flexible
char *argv[]	array of string pointers      scattered strings      fixed array size, flexible strings length
char argv[][]	2D char array	              continuous block       fixed size
